# BHAF MarketBridge Demo Video Guide

This guide is written to help you record a smooth, clear demo video for the client.

The goal is simple:

1. tell the MarketBridge story in a way that is easy to understand
2. move through the product in a clean order
3. notice any broken flow before or during the recording

## What Is MarketBridge?

BHAF MarketBridge is a digital platform built for Build Her A Future, BHAF.

It helps African women entrepreneurs become:

- visible
- trusted
- market-ready
- funding-ready
- easier to discover by buyers, funders, and partners

In simple terms, MarketBridge brings together:

- a verified entrepreneur directory
- a marketplace
- an opportunity board
- role-based dashboards
- ESG and impact reporting
- operational tools for BHAF to manage the ecosystem

## The Problem

The problem is not that women entrepreneurs in Africa are not building strong businesses.

The real problem is that many of them are still hard to find, hard to assess, and hard to support at scale.

That usually happens because:

- their profiles are not structured
- their business evidence is scattered
- their ESG and impact work is not documented clearly
- funders cannot easily compare readiness
- corporates cannot easily find trusted suppliers
- support organisations like BHAF need a better system to manage all of this in one place

## The Solution

MarketBridge solves this by creating one platform where:

- entrepreneurs can build a verified presence
- products and services can be discovered
- opportunities can be published and applied for
- funders can review and shortlist businesses
- corporates can source suppliers and run RFPs
- BHAF can track progress, evidence, and impact

## The Big Story You Are Telling in the Demo

The easiest way to explain MarketBridge is this:

“MarketBridge helps women-led businesses move from being invisible and disconnected to being visible, verified, and ready for growth.”

That is the story your video should follow.

So instead of making the demo feel like a list of features, make it feel like a journey:

1. first show the public face of the platform
2. then show how an entrepreneur enters and benefits
3. then show how a funder sees opportunity
4. then show how a corporate partner sees sourcing value
5. finally show how BHAF manages everything through admin tools

## Before You Start Recording

- Use a clean browser session.
- Use desktop view.
- Keep the credentials nearby so role switching is fast.
- Start from the landing page.
- Test sign-in once before recording.
- If a page is empty, move through it quickly and explain what it is for.

Important note about sign-up:

- If the environment supports real registration, you can use it.
- If not, show the sign-up screen briefly, then switch to the prepared entrepreneur account and continue the story from there.

## Suggested Demo Flow

This version is designed for a client-friendly demo of around 12 to 18 minutes.

Before the real recording, confirm:

## Final Advice

- Keep the language simple.
- Tell a story, not a feature list.
- Move from public pages to role-based value.
- Spend the most time on the entrepreneur, funder, corporate, and admin stories.
- If a support screen is empty, explain it briefly and move on.
- If something breaks, note the route immediately so it can be fixed before the final client demo.
